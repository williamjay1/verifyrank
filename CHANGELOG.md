# Changelog

## 0.2.0 — 2026-10-06 — prepared for public release

* Introduced a generic standard-library evaluation package accepting frozen selection weights and separate binary reference evidence through CSV or JSON.
* Added strict cross-row inventory, budget, evidence-state and shared-reference validation; no-follow-up identities remain decision-specific and unresolvable as archived observations.
* Added daily and shared-reference macro completion intervals, frozen verified-mass conditional scores, explicit undefined denominators and label-free coefficient priorities.
* Added cost-feasible greedy reference plans, hypothetical recovery probabilities, interval classification and a bounded returned-label-error sensitivity utility.
* Added a CLI, static HTML/CSV/JSON reports, synthetic examples, tutorial, schemas, MIT licence and computational tests.
* Verified source/wheel consistency, isolated installed-package CSV/JSON CLI execution and a local methane adapter parity check. The methane inputs and local validation reports are excluded from distribution.
* Added a proposed maintenance policy, Dockerfile and Python 3.12 GitHub Actions workflow. Container execution and remote CI execution have not been performed; configuration availability is not a claim of executed validation.
